TOPIC 6.2

Fixed Bias (Base Bias)

The simplest bias circuit, and why its Q-point will not stay put

The fixed bias circuit

FIXED BIAS (also called BASE BIAS) is the simplest way to bias a transistor. It uses only two resistors and one supply:

  • a base resistor RB connected from VCC to the base;
  • a collector resistor RC connected from VCC to the collector;
  • the emitter connected directly to ground.

The supply drives a current through RB into the base. Because VCC and RB are fixed, this base current is fixed, which gives the circuit its name.

Key points

  • Fixed bias (base bias) is the simplest bias circuit: two resistors, one supply.
  • RB runs from VCC to the base; RC from VCC to the collector.
  • The emitter goes straight to ground.
  • VCC and RB are fixed, so the base current is fixed.

Finding the Q-point

BASE LOOP: going from VCC through RB and the base-emitter junction to ground:

VCC = IB·RB + VBE, so IB = (VCC − VBE) / RB.

COLLECTOR CURRENT: in the active region, IC = β·IB.

COLLECTOR LOOP: VCE = VCC − IC·RC.

Worked example (VCC = 12 V, RB = 390 kΩ, RC = 2 kΩ, β = 100):

  • IB = (12 − 0.7) / 390 kΩ ≈ 29.0 µA
  • IC = 100 × 29.0 µA ≈ 2.90 mA
  • VCE = 12 − 2.90 mA × 2 kΩ ≈ 6.2 V

Since VCE is well above 0.2 V, the transistor is in the active region, and the Q-point (6.2 V, 2.90 mA) is close to the middle of the load line.

To design for a chosen IC, work backward: IB = IC/β, then RB = (VCC − VBE)/IB.

Key points

  • Base loop: IB = (VCC − VBE)/RB.
  • Active region: IC = β·IB; collector loop: VCE = VCC − IC·RC.
  • Example: 29.0 µA, 2.90 mA, 6.2 V, close to the middle of the load line.
  • Design backward: IB = IC/β, then RB = (VCC − VBE)/IB.

The big weakness: dependence on β

In fixed bias, the base current is fixed by VCC and RB alone. It does not depend on what the transistor does. The collector current is then IC = β·IB, so IC is directly proportional to β.

Suppose the transistor in the example is replaced by another of the same type whose β is 200 instead of 100:

  • IB stays at 29.0 µA
  • IC doubles to about 5.80 mA
  • VCE = 12 − 5.80 × 2 ≈ 0.4 V

The Q-point has moved from the middle of the load line to the edge of saturation. The amplifier would now clip badly. With β = 300, the transistor would be fully saturated.

Since β varies widely between devices and with temperature, fixed bias gives a very unstable Q-point.

Key points

  • IB is set by VCC and RB alone, so it ignores β.
  • IC = β·IB is directly proportional to β.
  • β = 200 instead of 100: IC ≈ 5.80 mA, VCE ≈ 0.4 V, at the edge of saturation; β = 300 saturates fully.
  • β varies between devices and with temperature, so the Q-point is very unstable.

Temperature and the stability factor

Temperature makes things worse. Including the leakage current, the collector current in fixed bias is:

IC = β·IB + (1 + β)·ICBO

As temperature rises, ICBO roughly doubles every 10 °C, and the full amount (1 + β)·ICBO is added to IC, because nothing in the circuit opposes it. A slight fall in VBE also increases IB a little.

The STABILITY FACTOR S measures how much IC changes when ICBO changes: S = ΔIC / ΔICBO. The ideal value is 1; larger values mean worse stability. For fixed bias:

S = 1 + β

With β = 100, S = 101: every 1 µA increase in leakage raises IC by about 101 µA. This is the WORST possible value for a CE bias circuit. Because there is no feedback, fixed bias is also prone to thermal runaway (topic 6.5).

Key points

  • With leakage: IC = β·IB + (1 + β)·ICBO.
  • ICBO doubles about every 10 °C and nothing opposes it; a falling VBE adds a little more IB.
  • S = ΔIC/ΔICBO; ideal 1. Fixed bias: S = 1 + β = 101 for β = 100, the worst case.
  • No feedback, so fixed bias is prone to thermal runaway.

Advantages, disadvantages and uses

Advantages:

  • very simple, only two resistors;
  • the Q-point is easy to calculate and to set by choosing RB;
  • no loading of the input signal by a resistor divider.

Disadvantages:

  • the Q-point depends directly on β, so it changes with every transistor;
  • poor thermal stability, S = 1 + β;
  • risk of thermal runaway.

Because of this, fixed bias is rarely used for linear amplifiers. It is mainly used in SWITCHING circuits, where the transistor is driven fully into cutoff or saturation and the exact value of β does not matter, as long as there is enough base current.

Key points

  • Pros: two resistors, easy to calculate and set with RB, no divider loading the input.
  • Cons: Q-point follows β, poor thermal stability (S = 1 + β), risk of thermal runaway.
  • Rarely used for linear amplifiers.
  • Mainly used for switching: with enough base current, β does not matter.

Summary

Fixed bias uses RB from VCC to the base. IB = (VCC − VBE)/RB is fixed, IC = β·IB and VCE = VCC − IC·RC. Because IC is proportional to β and S = 1 + β, the Q-point is very unstable. Fixed bias is simple but suitable mainly for switching, not for stable amplifiers.

Key formulas

  • IB = (VCC − VBE)/RB
  • IC = β·IB
  • VCE = VCC − IC·RC
  • IC = β·IB + (1 + β)·ICBO
  • S = 1 + β

Key points

  • RB from VCC to the base fixes IB = (VCC − VBE)/RB.
  • IC = β·IB, VCE = VCC − IC·RC.
  • IC ∝ β and S = 1 + β: a very unstable Q-point.
  • Simple, but suited mainly to switching, not stable amplifiers.
