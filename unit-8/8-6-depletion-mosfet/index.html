TOPIC 8.6

Depletion MOSFET

A normally-on MOSFET whose built-in channel the gate can empty or fill

Your device asks for reduced motion, so every animation starts paused. Press Play on any animation to run it. Sliders and dragging still update the picture.

Structure: a channel built in

A DEPLETION MOSFET has the same basic structure as an enhancement MOSFET: a p-type substrate, n+ source and drain, a thin oxide and a gate. The difference is that, during manufacturing, a thin lightly doped N-TYPE CHANNEL is diffused or implanted between the source and the drain, just under the oxide.

So a channel ALREADY EXISTS with zero gate voltage. Current can flow from drain to source as soon as VDS is applied, even with VGS = 0. That is why the depletion MOSFET is called "normally-on".

In the circuit symbol, the channel line is drawn as a SOLID line (not broken), showing that the channel is present without any gate voltage.

Key points

  • Same structure as an enhancement MOSFET, plus a thin implanted n-type channel under the oxide.
  • The channel exists at VGS = 0, so current flows as soon as VDS is applied.
  • It is a "normally-on" device: ID = IDSS = 6 mA at VGS = 0 here.
  • Its symbol has a solid channel line.

Depletion mode: negative VGS

Make the gate NEGATIVE with respect to the source. The negative gate repels electrons from the channel (and attracts holes from the substrate that recombine with channel electrons). The channel loses carriers: it is DEPLETED. Its conductivity falls, and so does the drain current.

At a sufficiently negative gate voltage, the channel is emptied of free electrons and ID falls to zero. This gate voltage is the PINCH-OFF VOLTAGE VP (also written VGS(off)). For our example, VP = −3 V.

In this mode the depletion MOSFET behaves much like an n-channel JFET, and its transfer characteristic follows the same Shockley equation:

ID = IDSS · (1 − VGS/VP)²

Example: VGS = −1.5 V gives ID = 6 × (1 − 0.5)² = 1.5 mA.

Key points

  • A negative gate repels electrons and depletes the channel, so ID falls.
  • At VGS = VP = −3 V (VGS(off)) the channel is empty and ID = 0.
  • Like a JFET: ID = IDSS(1 − VGS/VP)².
  • VGS = −1.5 V gives 1.5 mA.

Enhancement mode: positive VGS

Unlike a JFET, the depletion MOSFET can also work with a POSITIVE gate voltage. Its gate is insulated by the oxide, so a positive VGS causes no gate current (in a JFET, a positive gate would forward bias the gate junction).

A positive gate attracts MORE electrons into the channel, from the n+ regions and the substrate. The channel becomes more conductive and the drain current rises ABOVE IDSS. This is called the ENHANCEMENT MODE of the depletion MOSFET.

Shockley's equation still applies:

Example: VGS = +1 V gives ID = 6 × (1 + 1/3)² ≈ 10.7 mA.

So a depletion MOSFET can be operated with either polarity of gate voltage. Care is needed not to exceed the maximum drain current or the gate-oxide voltage rating.

Key points

  • The insulated gate allows positive VGS with no gate current.
  • A positive gate draws more electrons into the channel: ID rises above IDSS.
  • Shockley's equation still holds: VGS = +1 V gives about 10.7 mA.
  • Respect the maximum drain current and the gate-oxide voltage rating.

Drain characteristics

The drain characteristics of a depletion MOSFET look like those of a JFET, but with extra curves above the VGS = 0 curve for positive gate voltages. They have the same regions:

  • OHMIC (triode): small VDS, the channel acts as a resistor;
  • SATURATION: VDS ≥ VGS − VP, nearly constant current, used for amplification;
  • CUTOFF: VGS ≤ VP, no channel, ID = 0.

Key points

  • Like JFET curves, plus curves above VGS = 0 for positive gate voltages.
  • Ohmic: small VDS, the channel is a resistor.
  • Saturation: VDS ≥ VGS − VP, nearly constant current.
  • Cutoff: VGS ≤ VP, ID = 0.

Comparing JFET, depletion MOSFET and enhancement MOSFET

The three n-channel FET types are easiest to compare through their transfer characteristics:

  • JFET: conducts at VGS = 0 (ID = IDSS); works only with VGS between VP and 0 (negative). A positive gate would forward bias the gate junction.
  • DEPLETION MOSFET: conducts at VGS = 0 (ID = IDSS); works with negative VGS (depletion mode) AND positive VGS (enhancement mode).
  • ENHANCEMENT MOSFET: no current at VGS = 0; needs VGS above a positive threshold VT to conduct.

The MOSFETs have far higher input resistance than the JFET (the oxide insulates the gate completely), but their thin oxide can be damaged by static electricity, so they must be handled with ESD care.

Depletion MOSFETs are less common than enhancement types. They are used in some RF amplifiers, constant-current sources, start-up circuits in power supplies, and as load devices in older NMOS logic.

Key points

  • JFET: conducts at VGS = 0, works only for VP ≤ VGS ≤ 0.
  • Depletion MOSFET: conducts at VGS = 0, works with both polarities.
  • Enhancement MOSFET: off at VGS = 0, conducts above VT.
  • MOSFET gates have far higher input resistance but need ESD care.

Summary

A depletion MOSFET has a channel built in during manufacture, so it conducts at VGS = 0 with ID = IDSS. Negative VGS depletes the channel (ID falls to zero at VP); positive VGS enhances it (ID rises above IDSS). It follows ID = IDSS(1 − VGS/VP)² on both sides. Its symbol has a solid channel line. A p-channel depletion MOSFET works the same way with all polarities reversed.

Key formulas

  • ID = IDSS(1 − VGS/VP)² (saturation)
  • VDS(sat) = VGS − VP
  • VGS = 0 → ID = IDSS
  • VGS = VP → ID = 0

Key points

  • Built-in channel: conducts at VGS = 0 with ID = IDSS.
  • Negative VGS depletes (zero at VP); positive VGS enhances (above IDSS).
  • ID = IDSS(1 − VGS/VP)² on both sides.
  • Solid channel line in the symbol; p-channel has all polarities reversed.
