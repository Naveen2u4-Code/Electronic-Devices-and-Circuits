TOPIC 8.2

JFET Characteristics and Pinch-Off

Four regions on one graph, and one parabola that sums them up

The drain (output) characteristics

The DRAIN CHARACTERISTICS (or output characteristics) of a JFET are a family of graphs of drain current ID against drain-source voltage VDS, each drawn for one fixed value of gate-source voltage VGS. For our n-channel JFET, typical curves are drawn for VGS = 0, −1, −2, −3 and −4 V.

Each curve has the same shape: ID rises almost linearly at first, then bends over and becomes nearly flat. The VGS = 0 curve is the highest. More negative values of VGS give lower curves, and at VGS = VP = −4 V the curve lies on the axis (ID = 0).

The graph is divided into four regions: OHMIC, SATURATION, CUTOFF and BREAKDOWN, described next.

Key points

  • Drain characteristics: ID against VDS, one curve per fixed VGS.
  • Every curve rises almost linearly, bends, then becomes nearly flat.
  • VGS = 0 is the highest curve; at VGS = VP = −4 V, ID = 0.
  • Four regions: ohmic, saturation, cutoff and breakdown.

The ohmic region

At small values of VDS, to the LEFT of the pinch-off point, the channel is open all along its length. The JFET behaves like a resistor whose value is set by VGS. This is the OHMIC region (also called the linear or voltage-controlled-resistance region).

For very small VDS, the curves are nearly straight lines through the origin. Their slope is the channel conductance. A more negative VGS narrows the channel, so the line is less steep and the resistance is higher. The drain-source resistance in this region is approximately:

rd(on) = ro / (1 − VGS/VP)2

where ro is the resistance at VGS = 0.

This makes the JFET useful as a VOLTAGE-CONTROLLED RESISTOR, for example in automatic gain control and electronic attenuators.

Key points

  • Left of the pinch-off point the channel is open: the JFET is a resistor set by VGS.
  • Near the origin the curves are straight lines; slope = channel conductance.
  • More negative VGS → narrower channel → higher resistance.
  • Used as a voltage-controlled resistor (AGC, electronic attenuators).

Pinch-off and the saturation region

As VDS increases, the channel near the drain narrows until it pinches off at:

VDS(sat) = VGS − VP

For VGS = 0 this is 4 V; for VGS = −2 V it is 2 V. Plotting these points for all curves gives a curved dashed line, the PINCH-OFF LOCUS, which separates the ohmic region (left) from the saturation region (right).

To the right of this line, ID is nearly independent of VDS. This is the SATURATION region (also called the pinch-off or active region). The JFET behaves like a current source controlled by VGS, and this is the region used for AMPLIFIERS. The curves rise very slightly with VDS because the pinched region grows and the effective channel gets shorter (channel-length modulation).

The saturated current for VGS = 0 is IDSS, the largest current the JFET can carry in normal operation (10 mA in our example).

CUTOFF: for VGS at or below VP, the channel is fully closed and ID ≈ 0.

BREAKDOWN: at a high enough drain voltage, the gate-drain junction breaks down by avalanche and ID rises sharply. Since the drain-gate voltage is VDS − VGS, a more negative VGS makes breakdown happen at a LOWER VDS.

Key points

  • Pinch-off at VDS(sat) = VGS − VP; these points form the pinch-off locus.
  • Saturation: ID nearly independent of VDS; a VGS-controlled current source for amplifiers.
  • IDSS = saturated ID at VGS = 0 (10 mA); cutoff for VGS ≤ VP.
  • Breakdown depends on VDS − VGS: more negative VGS breaks down at lower VDS.

The transfer characteristic and Shockley's equation

In the saturation region, the drain current depends only on VGS (ignoring the slight slope). The graph of ID against VGS is called the TRANSFER CHARACTERISTIC. It follows SHOCKLEY'S EQUATION:

ID = IDSS · (1 − VGS/VP)2

It is a parabola that starts at ID = 0 at VGS = VP and rises to ID = IDSS at VGS = 0.

Useful points for quick sketching:

  • VGS = 0 → ID = IDSS
  • VGS = 0.3·VP → ID ≈ IDSS/2
  • VGS = 0.5·VP → ID = IDSS/4
  • VGS = VP → ID = 0

Example (IDSS = 10 mA, VP = −4 V): VGS = −1.2 V gives about 4.9 mA; VGS = −2 V gives 2.5 mA.

Key points

  • In saturation ID depends only on VGS: the transfer characteristic.
  • Shockley: ID = IDSS(1 − VGS/VP)2, a parabola from VP to IDSS.
  • Sketch points: 0 → IDSS; 0.3VP → ≈ IDSS/2; 0.5VP → IDSS/4; VP → 0.
  • Example: −1.2 V → about 4.9 mA; −2 V → 2.5 mA.

From drain curves to transfer curve

The transfer characteristic and the drain characteristics carry the same information. Draw a vertical line on the drain characteristics at any VDS in the saturation region. Each VGS curve crosses it at some ID. Plotting each of those (VGS, ID) pairs on a second graph gives the transfer characteristic. Because the saturation curves are nearly flat, the transfer curve is almost the same at any VDS in saturation.

In practice, JFET parameters vary widely between devices of the same type. For one popular small-signal JFET (2N5457), IDSS can be anywhere from 1 to 5 mA and VP from −0.5 to −6 V. So designers work with the transfer curve and biasing methods that tolerate this spread (topic 8.8).

Key points

  • A vertical line in saturation on the drain curves gives (VGS, ID) pairs.
  • Plotted together, those pairs form the transfer characteristic.
  • Nearly flat saturation curves: almost the same transfer curve at any VDS.
  • Wide device spread (2N5457: IDSS 1–5 mA, VP −0.5 to −6 V) needs tolerant biasing.

Summary

The JFET drain characteristics show four regions: ohmic (voltage-controlled resistor, left of the pinch-off locus VDS = VGS − VP), saturation (constant-current region used for amplification), cutoff (VGS ≤ VP) and breakdown. In saturation, ID = IDSS(1 − VGS/VP)2, the transfer characteristic. The two graphs are linked by projection, and device parameters vary widely.

Key formulas

  • ID = IDSS(1 − VGS/VP)2 (saturation)
  • VDS(sat) = VGS − VP
  • Ohmic: ID = (IDSS/VP2)[2(VGS − VP)VDS − VDS2]
  • rd(on) = ro/(1 − VGS/VP)2

Key points

  • Ohmic (left of VDS = VGS − VP): voltage-controlled resistor.
  • Saturation: constant current, used for amplification; cutoff for VGS ≤ VP; breakdown at high VDS.
  • Transfer characteristic: ID = IDSS(1 − VGS/VP)2.
  • The two graphs are linked by projection; parameters vary widely.
