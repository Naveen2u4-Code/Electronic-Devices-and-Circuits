Recap

Key points

  • A photodiode is a pn junction with a window over the junction, operated in reverse bias. Its symbol is a diode with arrows pointing in.
  • Dark: only the dark current flows (about nA). Light: each absorbed photon makes an electron-hole pair, the depletion field separates it, and a photocurrent Iλ ∝ light intensity flows.
  • A photon is absorbed only if hf ≥ Eg: cut-off λc = 1240/Eg nm (Si ≈ 1100 nm, Ge ≈ 1880 nm).
  • Iλ = ηqPλ/hc. Responsivity R = Iλ/P = ηλ(nm)/1240 A/W; silicon peaks around 0.5 to 0.6 A/W near 900 nm.
  • V-I: I = IS(eV/VT − 1) − Iλ. Third quadrant: photoconductive mode (sensor). Fourth quadrant: photovoltaic mode (solar cell).
  • Circuit: Vout = IλRL, response time τ = RLCj. Larger RL gives more output but a slower response. PIN and avalanche photodiodes are faster or more sensitive variants.
  • Uses: optocouplers, IR remote receivers, light meters, optical-fibre receivers, barcode scanners and smoke detectors.
