TOPIC 3.2

Zener Diode as a Voltage Regulator

One resistor and one Zener: holding the output steady when the input or the load changes

The shunt regulator circuit

A voltage regulator keeps the voltage across a load constant even when the input voltage changes (from mains variation or rectifier ripple) or when the load draws more or less current. The simplest regulator uses the Zener diode from topic 3.1.

A series resistor RS connects the unregulated input Vin to the output node. The Zener sits in parallel with the load RL, reverse biased with its cathode to the positive side. Because it is in parallel (in "shunt") with the load, this is called a SHUNT REGULATOR.

While the Zener is in breakdown, the load voltage is pinned at VL ≈ VZ. The currents then follow directly:

IS = (Vin − VZ) / RS  ·  IL = VZ / RL  ·  IZ = IS − IL

RS drops the difference between Vin and VZ. The Zener takes whatever part of IS the load does not use. Example, with a 5.1 V, 500 mW Zener, Vin = 12 V, RS = 120 Ω and RL = 250 Ω: IS = 6.9/120 = 57.5 mA, IL = 5.1/250 = 20.4 mA, so IZ = 37.1 mA.

This only works while the Zener is actually in breakdown. To check, remove the Zener and find the voltage the divider would give on its own:

Vopen = Vin · RL / (RS + RL)

If Vopen is above VZ, the Zener conducts and clamps the output at VZ. If it is below VZ, the Zener stays off and VL = Vopen: the regulator has dropped out. In practice the Zener current must also stay above IZK to hold VZ firmly.

The hand calculations here treat the Zener as ideal, fixed at 5.1 V. The animations use a real Zener curve, whose voltage rises a little with current (rZ) and sags near the knee. Their readouts therefore sit slightly off the ideal figures: VL ≈ 5.24 V and IZ ≈ 35 mA in this example.

Key points

  • RS in series from Vin, with the Zener (reverse biased) in parallel with the load.
  • In breakdown VL ≈ VZ, IS = (Vin − VZ)/RS, IL = VZ/RL, IZ = IS − IL.
  • The Zener soaks up the current the load does not take.
  • Regulation needs Vin·RL/(RS + RL) > VZ and IZ ≥ IZK. Otherwise it drops out.

Line regulation: when the input changes

Suppose Vin rises. The voltage across RS rises with it, so IS increases. The load still sees about VZ, so IL stays the same and all the extra current goes into the Zener. Because the Zener curve is so steep, this extra current raises VL only by ΔIZ·rZ.

In the small-signal picture, the Zener is a resistance rZ, and RS forms a voltage divider with rZ ∥ RL:

ΔVL / ΔVin = (rZ ∥ RL) / [ RS + (rZ ∥ RL) ] ≈ rZ / (RS + rZ)

This ratio, often quoted as a percentage or in mV per volt, is the LINE REGULATION. Smaller is better. For the example, rZ ≈ 8.5 Ω at IZ ≈ 37 mA, so the ratio is about 8.2/128 ≈ 6.4 %. A 4 V peak-to-peak ripple on the input becomes only about 0.26 V peak-to-peak at the output.

If Vin falls too far, Vopen drops below VZ and regulation is lost. Here that happens below Vin ≈ VZ(RS + RL)/RL = 5.1 × 370/250 ≈ 7.5 V. Below that point VL simply follows the divider.

Key points

  • A higher Vin raises IS. The extra current flows into the Zener, not the load.
  • Line regulation: ΔVL/ΔVin ≈ rZ/(RS + rZ), here about 6 %.
  • Ripple at the input is cut by the same factor.
  • Below Vin = VZ(RS + RL)/RL the regulator drops out.

Load regulation: when the load changes

Now hold Vin fixed and change the load. Since VL stays near VZ, the current through RS is set by Vin and hardly changes. So:

IZ + IL = IS ≈ constant

If the load draws more current, the Zener draws exactly that much less. The Zener acts as a current "reservoir" that gives up current to the load as needed. The small fall in IZ lowers VL slightly. The output resistance of the regulator is rZ ∥ RS ≈ rZ:

ΔVL / ΔIL ≈ −(rZ ∥ RS)   and   Load regulation = (VNL − VFL) / VFL × 100 %

where VNL and VFL are the output voltages at no load and at full load.

The reservoir is limited. When IL grows until IZ falls to IZK, the Zener leaves breakdown and VL collapses. For the example (Vin = 12 V, RS = 120 Ω), IS ≈ 57.5 mA, so the largest load current is about IS − IZK ≈ 56.5 mA, a minimum RL of about 5.1/0.0565 ≈ 90 Ω. In the plot, the real Zener's soft knee lets it hang on a little longer, to about 60 mA, while VL sags towards 4.7 V.

The opposite extreme is just as important. With no load the Zener carries all of IS and dissipates the most power: here PZ = 5.1 × 0.0575 ≈ 0.29 W.

Key points

  • IS is fixed by Vin and RS, so IZ + IL stays constant.
  • More load current means less Zener current. VL falls only by ΔIL·(rZ ∥ RS).
  • Maximum load: IL,max = IS − IZK. Beyond it the output collapses.
  • No load is the worst case for the Zener: it carries all of IS.

Designing the series resistor

The design task is to choose RS so the Zener stays between IZK and IZM for every combination of input voltage and load current. Treat the Zener as ideal (VL = VZ) and check the two extremes:

  • Lowest input, heaviest load (Vin,min, IL,max): the Zener current is smallest, and it must still be at least IZK. This sets the largest allowed RS.
  • Highest input, lightest load (Vin,max, IL,min): the Zener current is largest, and it must not exceed IZM. This sets the smallest allowed RS.

RS,max = (Vin,min − VZ) / (IZK + IL,max)   and   RS,min = (Vin,max − VZ) / (IZM + IL,min)

Choose a standard value between the two. If RS,min > RS,max, no resistor works: use a Zener with a higher power rating, or narrow the input or load range.

Worked example. VZ = 5.1 V, PZM = 0.5 W (IZM = 98 mA), IZK = 1 mA. Vin varies from 9 V to 15 V and IL from 0 to 30 mA.

  • RS,max = (9 − 5.1) / (0.001 + 0.030) = 3.9 / 0.031 ≈ 126 Ω.
  • RS,min = (15 − 5.1) / (0.098 + 0) = 9.9 / 0.098 ≈ 101 Ω.
  • Choose RS = 120 Ω (a standard E12 value).
  • Zener power, worst case (15 V, no load): IZ = 9.9/120 = 82.5 mA, so PZ = 5.1 × 0.0825 ≈ 0.42 W, under the 0.5 W rating.
  • Resistor power, worst case (15 V): PRS = (Vin,max − VZ)²/RS = 9.9²/120 ≈ 0.82 W, so use a 1 W resistor (2 W for margin).

Try raising IL,max to 40 mA below. RS,max drops to about 95 Ω, below RS,min, and no resistor works with this Zener.

Key points

  • RS,max = (Vin,min − VZ)/(IZK + IL,max) keeps the Zener in breakdown.
  • RS,min = (Vin,max − VZ)/(IZM + IL,min) keeps it within its power rating.
  • Pick a standard RS between them. If RS,min > RS,max, no value works.
  • Rate RS for (Vin,max − VZ)²/RS, and check PZ at maximum input with no load.

Summary

The Zener shunt regulator is a series resistor RS feeding a Zener in parallel with the load. While the Zener is in breakdown, VL ≈ VZ, and the Zener absorbs changes: extra input current from a higher Vin (line regulation ≈ rZ/(RS + rZ)), and current released by a lighter load (IZ + IL = IS). RS must lie between RS,min and RS,max so that IZK ≤ IZ ≤ IZM in every case.

The circuit is simple and cheap, but it is inefficient. The full IS flows all the time, even with no load, and both RS and the Zener waste power. It suits small load currents and voltage references. Larger loads use a transistor to carry the current, with the Zener only setting the reference voltage.

Key points

  • Series RS with a shunt Zener: VL ≈ VZ while IZK ≤ IZ ≤ IZM.
  • Line changes go into IZ. Load changes trade off against IZ, since IZ + IL = IS.
  • RS,min ≤ RS ≤ RS,max from the two worst cases.
  • Simple but wasteful: best for small currents and references.
