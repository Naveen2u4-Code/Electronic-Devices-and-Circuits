TOPIC 5.3

Current Components and the α, β Relationship

What each terminal current is made of, and the two current gains that describe a BJT

The three terminal currents

A BJT has three terminal currents: the emitter current IE, the base current IB and the collector current IC. For an NPN transistor in active mode, IB and IC flow into the transistor and IE flows out of it. For a PNP transistor all three directions are reversed.

Since charge cannot pile up inside the transistor, Kirchhoff’s current law always holds:

IE = IB + IC

The emitter current is the largest, the collector current is slightly smaller, and the base current is very small. For example, IE = 1.01 mA, IC = 1.00 mA and IB = 0.01 mA.

Key points

  • Three terminal currents: IE, IB, IC.
  • NPN active mode: IB and IC flow in, IE flows out; PNP reverses all three.
  • Kirchhoff’s current law: IE = IB + IC.
  • IE is largest, IC slightly smaller, IB very small.

What each current is made of

Inside an NPN transistor in active mode, each terminal current is made of several components:

Emitter current: IE = IEn + IEp

  • IEn: electrons injected from the emitter into the base (the useful part, by far the largest).
  • IEp: holes injected from the base into the emitter (wasted; small because the base is lightly doped).

Collector current: IC = ICn + ICBO

  • ICn: the injected electrons that survive the trip across the base and are collected.
  • ICBO: a small leakage current. The collector-base junction is reverse biased, so like any reverse-biased diode it carries a small reverse saturation current made of thermally generated minority carriers. Its name means “collector-to-base current with the emitter Open”.

Base current: IB = IEp + IBr − ICBO

  • IEp: holes the base injects into the emitter.
  • IBr: holes lost to recombination with electrons crossing the base.
  • minus ICBO: the leakage flows in the opposite direction at the base terminal.

Two efficiency factors describe the losses:

  • Emitter injection efficiency: γ = IEn / IE (close to 1).
  • Base transport factor: αT = ICn / IEn (close to 1).

Key points

  • IE = IEn + IEp: injected electrons (useful) plus injected holes (wasted).
  • IC = ICn + ICBO: collected electrons plus a small reverse leakage.
  • IB = IEp + IBr − ICBO.
  • γ = IEn/IE and αT = ICn/IEn, both close to 1.

Common-base current gain, α

The common-base current gain α (alpha) tells what fraction of the emitter current reaches the collector:

α = IC / IE (ignoring the tiny leakage ICBO)

It is the product of the two efficiencies: α = γ × αT.

Since some current is always lost, α is always less than 1. In practical transistors α is typically between 0.95 and 0.995.

Including leakage, the collector current is: IC = α·IE + ICBO.

Key points

  • α = IC/IE: the fraction of emitter current that reaches the collector.
  • α = γ × αT, always less than 1.
  • Typical α: 0.95 to 0.995.
  • With leakage: IC = α·IE + ICBO.

Common-emitter current gain, β

In most circuits the input current is the base current, so a more useful gain is the common-emitter current gain β (beta), also written hFE:

β = IC / IB

β is large, typically between 50 and 400 for small-signal transistors.

α and β are connected. Using IE = IB + IC and IC = α·IE:

β = α / (1 − α)    and    α = β / (1 + β)

Examples: α = 0.98 gives β = 49; α = 0.99 gives β = 99; α = 0.995 gives β = 199.

Notice that a tiny change in α near 1 causes a big change in β. That is why β varies widely between transistors of the same type, and why good circuits are designed not to depend on its exact value (Unit 6).

Key points

  • β = IC/IB (also hFE), typically 50 to 400.
  • β = α/(1 − α) and α = β/(1 + β).
  • α = 0.98, 0.99, 0.995 gives β = 49, 99, 199.
  • A tiny change in α near 1 changes β a lot, so circuits should not depend on its exact value.

Leakage currents ICBO and ICEO

ICBO is the collector-base leakage current with the emitter open. In silicon transistors it is very small (nanoamperes or less at room temperature), but it rises rapidly with temperature, roughly doubling for every 10 °C rise.

In the common-emitter connection, leakage is worse. With the base open, the leakage ICBO flowing into the base region acts just like a base current and is amplified by the transistor. The resulting collector current with the base open is:

ICEO = (1 + β)·ICBO

So the full common-emitter relation is:

IC = β·IB + (1 + β)·ICBO = β·IB + ICEO

With β = 100, ICEO is about 100 times ICBO. This temperature-dependent leakage is one cause of the thermal problems studied in Unit 6.

Key points

  • ICBO: collector-base leakage with the emitter open, nanoamperes or less in silicon.
  • It roughly doubles for every 10 °C rise.
  • Base open: the leakage is amplified, ICEO = (1 + β)·ICBO.
  • Full relation: IC = β·IB + ICEO.

Summary

The terminal currents obey IE = IB + IC. The emitter current is mostly electrons injected into the base (NPN), almost all of which reach the collector. α = IC/IE is just below 1, β = IC/IB is large, and they are related by β = α/(1 − α). Leakage currents ICBO and ICEO = (1 + β)ICBO are small but grow quickly with temperature.
