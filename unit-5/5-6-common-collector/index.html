TOPIC 5.6

Common Collector Configuration (Emitter Follower)

The collector is shared, the base is the input and the emitter is the output

The common collector circuit

In the common collector (CC) configuration, the collector is the shared terminal. It is connected directly to the supply VCC, and since a DC supply is a short circuit for signals, the collector is effectively at signal ground. The input is applied to the base, and the output is taken from the EMITTER, across an emitter resistor RE.

This circuit is better known as the EMITTER FOLLOWER, because the emitter voltage follows the base voltage.

Key points

  • The collector is the common terminal, tied directly to VCC.
  • A DC supply is a short circuit for signals, so the collector is at signal ground.
  • Input at the base; output at the emitter, across RE.
  • Also called the emitter follower: the emitter voltage follows the base voltage.

How the emitter follows the base

When the transistor is conducting, the base-emitter junction is forward biased, so the emitter is always about 0.7 V below the base:

VE = VB − VBE ≈ VB − 0.7 V

If the base voltage rises by 1 V, the emitter voltage also rises by almost exactly 1 V. The output therefore follows the input:

  • VOLTAGE GAIN is close to 1 (slightly less, typically 0.95 to 0.99);
  • there is NO phase inversion: the output is in phase with the input.

Although the voltage is not amplified, the current is. The output current is the emitter current, and IE = (β + 1)·IB. So the CURRENT GAIN is about β + 1, which is large.

If the input goes so low that VB is less than about 0.7 V (with no negative supply), the transistor cuts off and the output stops following; the bottom of the output waveform is clipped at 0 V.

Key points

  • VE = VB − VBE ≈ VB − 0.7 V while the transistor conducts.
  • Voltage gain just below 1 (typically 0.95 to 0.99), output in phase with input.
  • Current gain IE/IB = β + 1, which is large.
  • With no negative supply, inputs below about 0.7 V cut the transistor off: the output clips at 0 V.

Input and output resistance

The emitter follower is valued mainly for its resistances:

HIGH INPUT RESISTANCE: The source only has to supply the small base current, while the emitter resistor carries (β + 1) times more current. Seen from the base, RE therefore looks (β + 1) times larger:

Rin ≈ (β + 1)·RE (plus the small base-emitter resistance).

For β = 100 and RE = 1 kΩ, Rin ≈ 101 kΩ.

LOW OUTPUT RESISTANCE: Seen from the output, the resistance of the source driving the base is divided by (β + 1). Even a weak, high-resistance source can therefore drive a heavy, low-resistance load through an emitter follower. The output resistance is typically only a few ohms to a few tens of ohms.

Key points

  • Seen from the base, RE looks (β + 1) times larger: Rin ≈ (β + 1)·RE.
  • β = 100 and RE = 1 kΩ give Rin ≈ 101 kΩ.
  • Seen from the emitter, the source resistance is divided by (β + 1).
  • Rout is typically a few ohms to a few tens of ohms.

CC characteristics

The CC output characteristic (IE against VCE for constant IB) is almost identical to the CE output characteristic, because IE = IC + IB ≈ IC. The same saturation, active and cutoff regions appear. For this reason the CE characteristics are usually used for CC design as well. The input characteristic (IB against VCB, at constant VCE) is different in shape, but it is rarely needed in practice.

Key points

  • CC output characteristic: IE against VCE at constant IB.
  • IE = IC + IB ≈ IC, so it almost matches the CE family.
  • Same saturation, active and cutoff regions; CE curves are used for CC design.
  • The CC input characteristic (IB against VCB) is rarely needed.

Comparing CB, CE and CC

All three configurations use the same transistor; only the connections differ.

  • Common base: current gain α (< 1), high voltage gain, very low input resistance, very high output resistance, no phase inversion. Used for high-frequency and current-buffer stages.
  • Common emitter: current gain β (high), high voltage gain, highest power gain, medium input and output resistance, 180° phase inversion. Used for general amplification and switching.
  • Common collector: current gain β + 1 (high), voltage gain about 1, high input resistance, low output resistance, no phase inversion. Used as a buffer and impedance matcher.

Key points

  • Same transistor in all three; only the connections differ.
  • CB: α < 1, high voltage gain, very low Rin, very high Rout, in phase.
  • CE: high β, high voltage gain, highest power gain, medium resistances, 180° inversion.
  • CC: β + 1, voltage gain about 1, high Rin, low Rout, in phase: a buffer.
