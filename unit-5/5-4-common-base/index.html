TOPIC 5.4

Common Base Configuration and Characteristics

The base is shared, the emitter is the input and the collector is the output

What is a transistor configuration?

A transistor has three terminals, but a circuit with an input and an output needs four connections (two for the input, two for the output). So one transistor terminal must be shared by both the input and the output. That shared terminal is called the common terminal, and it gives the configuration its name:

  • Common base (CB): base shared; input at the emitter, output at the collector.
  • Common emitter (CE): emitter shared; input at the base, output at the collector.
  • Common collector (CC): collector shared; input at the base, output at the emitter.

Each configuration has different gains and input/output resistances, so each suits different jobs. This topic covers common base.

Key points

  • Input and output need four connections; a transistor has three, so one terminal is shared.
  • The shared (common) terminal names the configuration: CB, CE or CC.
  • Common base: input at the emitter, output at the collector, base common.
  • Each configuration has its own gains and input/output resistances.

The common base circuit

In the common base configuration of an NPN transistor, the base is connected to ground (common). The input is applied between the emitter and the base, and the output is taken between the collector and the base.

For active operation:

  • a supply VEE forward biases the emitter-base junction: the emitter is made negative with respect to the base by about 0.7 V;
  • a supply VCC reverse biases the collector-base junction: the collector is made positive with respect to the base.

The input current is IE and the output current is IC. Since IC = α·IE with α slightly less than 1, the current gain of a CB circuit is just below 1. But the circuit can still give a large voltage gain, because the input resistance is very low (tens of ohms) while the output resistance is very high (hundreds of kilohms to megohms). A small input voltage creates a current that flows almost unchanged into a large load resistance, producing a large output voltage. There is no phase inversion between input and output.

Key points

  • Base grounded; input between emitter and base, output between collector and base.
  • VEE forward biases the emitter-base junction; VCC reverse biases the collector-base junction.
  • Current gain α = IC/IE, just below 1.
  • Low input and high output resistance give a large voltage gain, with no phase inversion.

Input characteristics

The input characteristic is a graph of the input current IE against the input voltage VEB, measured while the output voltage VCB is held constant.

It looks like the forward characteristic of a diode, because the input is just the forward-biased emitter-base junction. Almost no current flows until VEB reaches the cut-in voltage of about 0.5 V for silicon; beyond about 0.7 V the current rises very steeply.

When VCB is increased, the curves shift slightly to the left: for the same VEB, a little more emitter current flows. This happens because the wider collector depletion region makes the effective base thinner (the Early effect, topic 5.10), which steepens the electron gradient in the base.

The input resistance ri = ΔVEB / ΔIE (at constant VCB) is the inverse slope of the curve. Because the curve is so steep, ri is very low, typically tens of ohms.

Key points

  • Input characteristic: IE against VEB, with VCB held constant.
  • Diode-like: cut-in about 0.5 V, very steep rise beyond about 0.7 V.
  • Higher VCB shifts the curves slightly left (Early effect).
  • ri = ΔVEB/ΔIE is very low, typically tens of ohms.

Output characteristics

The output characteristic is a graph of the output current IC against the output voltage VCB, drawn for several constant values of the input current IE (for example 1, 2, 3, 4 and 5 mA). It has three regions:

Active region: VCB positive (collector junction reverse biased). Here IC ≈ α·IE and the curves are almost flat and horizontal, rising only very slightly with VCB. The collector current is set by IE, not by VCB. Note that IC is already almost equal to α·IE even at VCB = 0, because the built-in field of the collector junction alone is enough to collect the electrons.

Saturation region: To the left of VCB = 0, when VCB is made negative by about 0.5 to 0.7 V, the collector-base junction becomes forward biased. The collector then starts injecting carriers back into the base, and IC drops quickly toward zero.

Cutoff region: When IE = 0, only the small leakage current ICBO flows in the collector. The curve lies along the horizontal axis.

At very high VCB the collector junction breaks down and IC rises sharply (BVCBO, topic 5.11).

The output resistance ro = ΔVCB / ΔIC (at constant IE) is very high because the curves are nearly flat.

Key points

  • Output characteristic: IC against VCB, for constant values of IE.
  • Active: IC ≈ α·IE, nearly flat, already so at VCB = 0.
  • Saturation: VCB about −0.5 to −0.7 V forward biases the collector junction and IC falls toward zero.
  • Cutoff: IE = 0, only ICBO flows; ro = ΔVCB/ΔIC is very high.

Properties and uses of the CB configuration

Common base properties:

  • Current gain: α, slightly less than 1.
  • Voltage gain: high.
  • Input resistance: very low (tens of ohms).
  • Output resistance: very high.
  • Phase: output in phase with input (no inversion).

Because the base is grounded, it shields the output from the input, so CB stages work well at high frequencies. They are used in radio-frequency amplifiers, as a current buffer that accepts current from a low-resistance source and delivers it to a high-resistance load, and as the upper transistor in the cascode amplifier.

Key points

  • Current gain α just below 1, high voltage gain, output in phase with input.
  • Very low input resistance, very high output resistance.
  • The grounded base shields output from input, so CB works well at high frequencies.
  • Uses: RF amplifiers, current buffers, the upper transistor of a cascode.

Summary

In common base, the input is at the emitter and the output at the collector, with the base common. The input characteristic is like a forward diode curve; the output characteristic is nearly flat with IC ≈ α·IE in the active region. CB has a current gain just below 1, high voltage gain, very low input resistance, very high output resistance and no phase inversion.

Key points

  • CB: input at the emitter, output at the collector, base common.
  • Input curve is diode-like; output curves are flat with IC ≈ α·IE.
  • Current gain just below 1, high voltage gain, very low ri, very high ro, no phase inversion.
