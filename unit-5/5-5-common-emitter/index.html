TOPIC 5.5

Common Emitter Configuration and Characteristics

The emitter is shared, the base is the input and the collector is the output

The common emitter circuit

In the common emitter (CE) configuration, the emitter is shared by the input and the output and is usually connected to ground. The input signal is applied between the base and the emitter, and the output is taken between the collector and the emitter.

For an NPN transistor in active mode, a supply VBB with a base resistor RB drives a small base current IB into the base, forward biasing the base-emitter junction (VBE ≈ 0.7 V). A supply VCC with a collector resistor RC makes the collector positive, keeping the collector-base junction reverse biased.

The input current is IB and the output current is IC. Since IC = β·IB, the CE configuration has a LARGE current gain. It also gives a large voltage gain, so its power gain is the highest of the three configurations. This is why common emitter is the most widely used configuration for amplifiers.

One special feature: the output voltage is 180° out of phase with the input. When the input rises, IC rises, the drop across RC increases, and the collector voltage falls.

Key points

  • Emitter common (grounded); input between base and emitter, output between collector and emitter.
  • VBB and RB forward bias the base-emitter junction; VCC and RC reverse bias the collector-base junction.
  • IC = β·IB: large current gain, large voltage gain, highest power gain.
  • The output is 180° out of phase with the input.

Input characteristics

The INPUT CHARACTERISTIC of the CE configuration is a graph of base current IB against base-emitter voltage VBE, measured at a constant collector-emitter voltage VCE.

Like the CB input curve, it has the shape of a forward-biased diode characteristic: very little current below the cut-in voltage of about 0.5 V, then a steep rise around 0.6 to 0.7 V for silicon. The current is in microamperes rather than milliamperes, because only the small base current is plotted.

When VCE is raised from 0 to about 1 V, the curve shifts to the RIGHT: a slightly larger VBE is needed for the same IB. The reason is that a larger VCE widens the collector depletion region, which narrows the effective base width. A narrower base means less recombination, so less base current is needed. Above about 1 V, further increases in VCE have little extra effect, so the curves for higher VCE almost overlap.

The INPUT RESISTANCE ri = ΔVBE / ΔIB at constant VCE. Because IB is much smaller than IE, the CE input resistance is much higher than in CB, typically around a kilohm.

Key points

  • Input characteristic: IB against VBE, with VCE held constant.
  • Diode-like: cut-in about 0.5 V, steep rise at 0.6 to 0.7 V; current in µA.
  • Raising VCE from 0 to about 1 V shifts the curve right; beyond 1 V the curves almost overlap.
  • ri = ΔVBE/ΔIB, around a kilohm, much higher than in CB.

Output characteristics

The OUTPUT CHARACTERISTIC of the CE configuration is a graph of collector current IC against collector-emitter voltage VCE, drawn for several constant values of base current IB (for example 0, 20, 40, 60, 80 and 100 µA). It has three regions:

SATURATION REGION: at very low VCE, below about 0.2 to 0.3 V. Here both junctions are forward biased. IC rises steeply with VCE and is LESS than β·IB, because the collector cannot collect all the carriers the base current could support. The voltage across a saturated transistor is VCE(sat) ≈ 0.2 V.

ACTIVE REGION: VCE above saturation. Here IC ≈ β·IB, and each curve is nearly flat, rising slowly with VCE because of the Early effect (topic 5.10). The curves are spaced roughly equally for equal steps of IB. This is the region used for amplification.

CUTOFF REGION: when IB = 0, only the small leakage current ICEO = (1 + β)·ICBO flows. The region below the IB = 0 curve is cutoff. The transistor acts as an open switch.

At high VCE the collector junction breaks down. In CE the breakdown voltage BVCEO is lower than the CB value BVCBO (topic 5.11).

The OUTPUT RESISTANCE ro = ΔVCE / ΔIC (at constant IB) is the inverse slope of a curve in the active region. It is lower than in CB, because the CE output curves slope more.

Key points

  • Output characteristic: IC against VCE, for constant values of IB.
  • Saturation: VCE below about 0.2 to 0.3 V, both junctions forward, IC < β·IB.
  • Active: IC ≈ β·IB, curves nearly flat with an Early-effect slope; used for amplification.
  • Cutoff: IB = 0, only ICEO = (1 + β)·ICBO flows; ro is lower than in CB.

Measuring β from the characteristics

The output characteristics let us measure the current gain:

  • DC current gain: βdc = hFE = IC / IB at a chosen operating point.
  • AC (small-signal) current gain: βac = hfe = ΔIC / ΔIB, measured between two neighbouring curves at the same VCE.

In practice β is not a fixed number. It changes with collector current (it is lower at very small and very large currents), with temperature (it increases as temperature rises), and from one transistor to another of the same type. Datasheets therefore give a minimum and maximum value. Good circuit design does not depend on an exact β (Unit 6).

Key points

  • βdc = hFE = IC/IB at one operating point.
  • βac = hfe = ΔIC/ΔIB between neighbouring curves at the same VCE.
  • β falls at very low and very high IC, rises with temperature and varies between devices.
  • Datasheets give a minimum and maximum β; good designs do not rely on an exact value.

Properties and uses of the CE configuration

Common emitter properties:

  • Current gain: β, large (typically 50-400).
  • Voltage gain: high.
  • Power gain: the highest of the three configurations.
  • Input resistance: medium (around a kilohm).
  • Output resistance: medium to high (tens of kilohms).
  • Phase: output inverted by 180°.

Uses: general-purpose voltage amplifiers in audio and signal circuits, and electronic switches (driving LEDs, relays and logic).

Key points

  • Large current gain β (typically 50-400), high voltage gain, highest power gain.
  • Medium input resistance (about 1 kΩ), medium to high output resistance (tens of kΩ).
  • Output inverted by 180°; too large an input clips at cutoff (top) and saturation (bottom).
  • Uses: voltage amplifiers in audio and signal circuits, and switches for LEDs, relays and logic.

Summary

In common emitter, the input is at the base and the output at the collector, with the emitter common. The input characteristic is a diode-like curve in microamperes; the output characteristics show saturation, active (IC ≈ β·IB) and cutoff regions. CE gives large current, voltage and power gain with a 180° phase inversion, which makes it the most widely used configuration.

Key points

  • CE: input at the base, output at the collector, emitter common.
  • Input curve is diode-like in µA; output curves show saturation, active (IC ≈ β·IB) and cutoff.
  • Large current, voltage and power gain with a 180° phase inversion: the most widely used configuration.
